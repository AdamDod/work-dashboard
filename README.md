# Work dashboard

A responsive, static work dashboard built with HTML and CSS. Open `index.html` in a browser to preview it.

The tasks, project progress, schedule, and summary numbers are sample content. Checkboxes can be ticked in the browser but changes are not saved.

## Publish with GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, select your default branch and the **/ (root)** folder, then save. GitHub Pages serves `index.html` from the repository root; no build step is needed.
